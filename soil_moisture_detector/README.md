# Soil Moisture Detector

An electronics project designed to detect soil moisture levels and help determine whether soil is dry or wet. This project demonstrates the basic principles of sensor-based detection and electronic alert systems.

## Features

- Detects moisture in soil using a soil moisture sensor.
- Identifies whether the soil is dry, moist, or moderate.
- Provides an indication or alert based on the detected moisture level.
- Demonstrates basic electronics and sensor applications.
- When the soil is wet, the green will light up. When the soil is moderate, the yellow will light up. When dry, it will light up the red light and the 
buzzer will alert.

## Components

- Soil moisture sensor
- Jumper wires
- Breadboard
- 3x LED
- 3x 220Ohms resistors
- Buzzer

## How It Works

The soil moisture sensor detects changes in the moisture content of the soil. Based on the sensor readings, the circuit determines whether the soil is dry, moist, or just moderate and activates the corresponding output or alert.

## Purpose

This project was developed for educational purposes to demonstrate how soil moisture detection can be used in basic electronics and plant care applications.
